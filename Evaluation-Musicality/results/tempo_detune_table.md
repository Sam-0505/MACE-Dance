Real dance scored with BPL against a perfectly regular beat grid whose interval is the own mean beat interval × (1 + e); e = 0 is the metronome control. The band-pass follows the grid tempo, as BPL would for a song e % faster or slower. Right tempo − grid = paired difference between the 0 % grid and the detuned grid (one-sided test of the 0 % grid scoring higher). Drift = median accumulated phase error over the scored 26 s window, in beats. p = one-sided sign-flip permutation of Original − grid > 0 over units (FineDance 19 songs, Motorica 52 pieces; 10,000). Beyond ±7.5 % the true beat rate leaves the 15 % band.
